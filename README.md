# Abismo Sombrio

ARPG de masmorra no estilo clássico (dark fantasy), feito em HTML5 Canvas puro, sem dependências. Roda no navegador do celular e do PC.

## Como jogar
- **Toque/clique** para andar. Se segurar, o herói anda sem parar.
- **Toque num inimigo** para atacar até ele cair.
- 🔥 Bola de fogo (1 / botão direito) · ✴️ Explosão sagrada (2) · 🧪 Poção (Q) · 🎒 Inventário (I)

## Recursos
- Masmorras geradas proceduralmente, iluminação dinâmica, tochas e minimapa
- Itens Comum, Mágico, Raro e Lendário com atributos aleatórios
- XP, níveis, inimigos elite e um chefe a cada 3 andares
- Mercador para vender itens e comprar poções

## Rodar
Abra o `index.html` no navegador ou ative o GitHub Pages (Settings → Pages → branch `main`, pasta raiz).
